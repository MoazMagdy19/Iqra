# 📖 اقرأ من أول وجديد — Prototype (HTML / CSS / JS فقط)

نفس الـ Prototype، لكن بدون React أو Vite أو أي أدوات بناء — ملفات ساكنة
فقط: `index.html` + `style.css` + `script.js`. لا يوجد Backend ولا
Database ولا AI حقيقي؛ كل البيانات Mock وكل التحليل Simulation.

## التشغيل

أسهل طريقة: افتح `index.html` مباشرة في المتصفح (دبل كليك عليه).

لو الصوت مايشتغلش بهذه الطريقة (بعض المتصفحات بتقيّد `file://`)، شغّل
خادوم بسيط من داخل المجلد:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو بأي خادوم ساكن تاني تفضّله (live-server، أو إضافة VS Code المعروفة
بنفس الاسم، إلخ).

## الملفات

```
index.html   هيكل الشاشات الأربع كلها في صفحة واحدة
style.css    كل التصميم (أزرق + أبيض، RTL، خط Tajawal)
script.js    كل المنطق: التنقل، المحاكاة، والصوت الحقيقي
```

## الصوت: حقيقي 🔊

أزرار الاستماع تستخدم **Web Speech API** المدمجة في المتصفح
(`speechSynthesis`) — صوت حقيقي بدون خادوم أو إنترنت. جرّب زر
**"🔊 تجربة الصوت قبل العرض"** في شاشة البداية قبل أي عرض أمام اللجنة.

لو الصوت صامت: تأكد إن الجهاز مش على Mute، استخدم Chrome أو Edge
(أفضل دعم عربي)، وشغّل الصفحة عبر خادوم محلي مش بفتح الملف مباشرة.
لو فتحت Console (F12) واكتبت `speechSynthesis.getVoices().length`
وطلعت `0`، يبقى مفيش أصوات (Voices) مركّبة على النظام نفسه.

**تحليل نطق الطفل (Recording → 90%)** و **استخراج النص من الصفحة
(OCR)** لسه محاكاة بالكامل كما طُلب — محتاجين فعليًا AI/Backend حقيقي.

## سيناريو العرض

١. ابدأ الآن ← ٢. اختر ملف (محاكاة رفع) ← ٣. ابدأ القراءة ← ٤. استمع
(تظليل + صوت حقيقي) ← ٥. حان دورك ← ٦. اضغط الميكروفون (عدّ تنازلي
ونتيجة ٩٠٪) ← ٧. Simulate Mistake (سيناريو الخطأ في «صغير» + تدريب
صوتي + نطق صحيح).
